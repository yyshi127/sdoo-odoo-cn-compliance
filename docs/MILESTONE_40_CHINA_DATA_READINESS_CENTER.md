# M40 中国数据准备中心

## 目标

合规扫描、风险识别和报告生成不能直接建立在散落的数据导入记录上。本次增量把中国包已经具备的外部数据集、封存完整性、真实性验证、解析批次和规范化数量集中到一个“数据准备中心”，让实施人员在进入规则扫描前先确认数据是否可用。

## 已交付

- 新增 `sudo.cn.external.dataset` 展示字段：
  - `cn_data_readiness_stage`：待补齐、已封存、可用于扫描、需复核、受阻、已替代。
  - `cn_data_readiness_period_label`：覆盖期间。
  - `cn_data_readiness_record_count`：电子发票和税务数据的规范化记录合计。
  - `cn_data_readiness_next_action`：面向实施人员的下一步处理提示。
- 新增 `sudo.compliance.profile.action_cn_open_workbench_data_readiness()`，从中国合规工作台按当前合规档案打开数据准备中心。
- 新增 `views/data_readiness_center_views.xml`：
  - kanban：按数据集类型分组，展示封存、真实性、完整性、源记录、规范化记录和下一步。
  - list：适合批量排查，包含解析批次与规范化入口。
  - search：按数据类型、状态、完整性、公司和月份分组。
- 工作台新增“数据准备中心”按钮，作为规则扫描前置入口。
- 国家包能力增加 `china_data_readiness_center`。
- 版本升级到 `19.0.1.37.0`，并新增迁移脚本刷新国家包元数据。

## 验收点

- 从中国合规工作台进入数据准备中心时，只显示当前合规档案的数据集。
- 封存后被篡改或真实性验证失败的数据集会显示为受阻。
- 已封存但真实性待验证、或已封存但尚未规范化的数据会显示为需复核。
- 完整性已验证且规范化完成的数据可以作为后续对账、风险扫描和报告引用的数据基础。

## 限制

- 本次是数据准备的可视化与导航层，不新增外部数据采集适配器。
- 当前运行库仍因服务器 PostgreSQL 故障无法做真实 Odoo 升级验证；已完成静态 XML/Python/插件契约校验。
