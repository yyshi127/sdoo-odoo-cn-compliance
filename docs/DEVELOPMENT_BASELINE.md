# 开发基线

## 技术基线

- Odoo：19
- 核心依赖：`account`、`l10n_cn`、`sudo_global_finance`
- 中国国家包技术名：`sudo_country_pack_cn`
- Python 与 XML 风格遵循 Odoo 19 addon 规范

## 数据环境

- `odoo_2601` 仅作为只读真实数据来源。
- 中国合规开发测试使用独立中和副本 `odoo_2601_cn_compliance_dev`。
- 数据库与 filestore 成对复制；开发结果不得反向同步到源库。
- 对外演示、第三方测试和外部 AI 处理必须使用另建的脱敏副本。

## 发布门禁

每个里程碑至少满足：

1. Python、XML 和 manifest 静态检查通过。
2. Odoo 模块可在独立数据库安装和升级。
3. 自动化测试无失败、无错误。
4. 多公司、权限、数据不足和审计边界经过验证。
5. 不包含密钥、真实业务数据和不可公开的服务器配置。

正式规则还必须满足官方来源治理、版本边界测试、独立审批和中国财税专业签核。
