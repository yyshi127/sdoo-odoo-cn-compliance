# M42 中国整改复扫可见性

## 目标

中国合规闭环不仅要创建整改任务，还要让用户清楚看到整改是否已经提交复核、是否可以发起验证复扫、复扫是否已经排队、是否失败以及最终是否闭环。本次增量不改变底层复扫逻辑，只把已有任务状态机和验证评估入口做成更清晰的整改跟踪体验。

## 已交付

- 在 `sudo.compliance.task` 中国整改显示层新增：
  - `cn_remediation_rescan_stage`：整改中、已逾期、受阻、可发起复扫、复扫中、复扫未通过、证据待核验、已闭环、已取消。
  - `action_cn_open_remediation_verification_assessment()`：打开该整改任务对应的验证复扫评估。
- 中国整改跟踪列表新增复扫闭环状态，并在可复扫时显示“发起复扫”，已有复扫批次时显示“查看复扫”。
- 中国整改跟踪卡片新增复扫闭环徽章和复扫入口按钮。
- 国家包能力增加 `china_remediation_rescan_visibility`。
- 版本升级到 `19.0.1.39.0`，并新增迁移脚本刷新国家包元数据。

## 设计边界

- 本次只增强可见性与导航，不改变 `action_queue_verification_scan()` 的权限、状态前置条件和审计记录。
- 复扫是否通过仍由规则评估结果、正式证据和任务验证动作共同决定。
- 当前运行库仍因服务器 PostgreSQL 故障无法做真实 Odoo 升级验证；已完成静态 XML/Python/插件契约校验。
