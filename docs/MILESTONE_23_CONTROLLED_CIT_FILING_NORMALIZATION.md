# 里程碑 23：受控企业所得税申报标准化台账

## 目标

为企业所得税季度预缴和年度汇算清缴建立独立、不可改写、可追溯的标准化申报台账，补齐 `CN-CIT` 义务到真实外部申报事实之间的数据入口。

交付版本：`sudo_country_pack_cn 19.0.1.20.0`。

本里程碑只登记企业依法取得并受控封存的申报来源值，不连接电子税务局，不自动提交申报，不计算法定税率、优惠、应纳税额或截止日，也不把字段完整、金额一致或申报状态解释为税务机关认定或税务合规结论。

## 数据入口

外部监管数据新增 `cit_filing` 类型。导入继续复用 `sdoo.cn.tax-data.v1` 受控 UTF-8 JSON 契约和既有封存流程：

1. 数据集必须属于中国合规档案，明确来源系统、覆盖期间、取得依据和覆盖范围。
2. 数据集只能包含一份非空标准化 JSON 源文件，并在独立复核或受控例外后封存。
3. 导入前重新核对源附件 SHA-256、数据集封存校验和、声明记录数和数据集类型。
4. 失败导入不会替代上一份成功结果；新成功结果只把旧结果标记为已被替代，不删除历史记录。

示例契约见 `docs/samples/cn_cit_filing_contract_v1.example.json`。示例金额只是演示来源字段，不是系统计算结果或税务建议。

## 标准化口径

每条企业所得税申报记录保留：

- 纳税人名称、统一社会信用代码、主管辖区和精确所属期间。
- 纳税年度、季度预缴或年度汇算等来源期间类型、申报表类型代码和修订关系。
- 申报状态、申报时间和官方参考号。
- 会计利润总额、纳税调增额、纳税调减额和应纳税所得额。
- 应纳所得税额、减免所得税额、抵免所得税额和已预缴所得税额。
- 应补所得税额与应退所得税额两个独立方向。
- 原申报表行代码、行名称、金额性质、本期金额、本年累计和来源申报税率。

所有汇总金额和行金额均使用独立的 `has_*` 标记区分“来源明确提供 0”和“来源没有该字段”。系统不会把缺失金额静默补零，也不会用应补减应退形成一个缺少法律语义的净额。

## 数据质量

以下情况形成明确错误并阻止记录作为可靠勾稽依据：

- 纳税主体与当前 Odoo 公司不一致。
- 所属期间超出数据集声明范围、日期无效或币种未知。
- 纳税年度格式无效、缺少申报表类型代码。
- 缺少应纳税所得额，或应补与应退两个来源字段均未提供。

以下情况保留记录并形成警告，要求后续人工复核：

- 申报期间类型、申报状态或申报表行金额性质未识别。
- 已申报记录缺少申报时间或参考号。
- 同时存在正数应补和正数应退金额。
- 通常非负的来源汇总金额为负，或来源税率不在 0 至 1 之间。
- 标准化行没有本期金额和本年累计金额。

契约层拒绝未知字段、重复 JSON 键、重复源记录键、重复申报表行代码、非标准 JSON 常量和声明数量不一致，防止上游悄悄改变数据语义。

## 审计与权限

- 导入运行、企业所得税申报记录和申报表行只能由受控内部标记创建，不能手工创建、修改、复制或删除。
- 输入文件、数据集封存、标准化契约、规范化输出和每条记录分别保存 SHA-256。
- 普通合规用户按允许公司只读；合规管理员可以发起受控导入，但同样不能改写导入结果。
- 企业所得税申报记录和行具有独立公司记录规则，跨公司直接搜索不可见。
- 当前有效结果同时要求导入成功、数据集仍为当前封存版本且源文件完整性正常。

## Odoo 原生体验

- 外部监管数据可选择“企业所得税申报数据”，封存后使用原生按钮执行申报缴税受控导入。
- 数据集统计按钮直接打开当前企业所得税申报台账。
- 导入运行表单独立展示企业所得税记录数和结果明细。
- 台账列表优先显示纳税年度、期间类型、申报状态、会计利润、应纳税所得额以及应补和应退两个方向。
- 记录表单先展示数据错误、来源真实性和结论边界，再分组展示申报范围、账税利润调整、税额补退、标准化行和审计指纹。

## 验收

- 本地静态契约、Python/XML 编译及 34 项纯 Python 测试全部通过，其中税务数据契约测试 16 项。
- 企业所得税所在的申报缴税标准化测试类执行 16 个运行时方法，Odoo 统计 18 项，结果为 `0 failed / 0 errors`。
- 全量空库新装执行 172 个运行时方法，Odoo 统计 194 项，结果为 `0 failed / 0 errors`。
- 从 `19.0.1.19.0` 升级至 `19.0.1.20.0` 时已执行 `19.0.1.20.0` 后迁移，并再次通过 172 个运行时方法、194 项 Odoo 统计，结果为 `0 failed / 0 errors`。
- 真实数据隔离副本升级后仍为 15,589 张凭证、44,651 条分录；借贷合计以及 `account_move`、`account_move_line` 逐行摘要与升级前完全一致。
- 本地与隔离服务器的 78 个插件文件 SHA-256 逐一一致；主 Odoo 服务保持 `active`，登录入口返回 HTTP `303`。

## 当前边界与下一步

本里程碑建立的是受控申报事实，不是企业所得税计算引擎。下一阶段应在精确会计期间、受控损益口径和真人复核调整基础上，建立“会计利润 -> 纳税调整 -> 应纳税所得额 -> 来源申报 -> 所得税缴款”的可解释勾稽；任何税率、优惠、扣除、亏损弥补、关联交易或跨境判断仍必须来自完成官方来源治理和中国财税专业签核的规则。
