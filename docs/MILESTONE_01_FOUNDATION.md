# 里程碑 01：中国国家包基础能力

## 交付范围

第一里程碑只建立安全、可安装的国家包基础，不发布任何未经治理的中国财税规则。

1. 注册 `CN` 国家包和能力清单。
2. 初始化已配置为中国的公司合规档案。
3. 建立增值税、企业所得税、个人所得税扣缴、附加税费、印花税、社会保险费和资料留存候选义务。
4. 候选义务统一使用 `unknown` 适用状态，且不绑定虚构官方来源。
5. 初始化向导使用中国登记默认值，切换国家后清除中国专属默认值。
6. 自动化测试覆盖初始化幂等、多公司隔离和数据不足边界。

## 验收标准

- Python、XML 和 manifest 静态解析通过。
- Odoo 测试数据库可安装、升级模块。
- 七类候选义务不产生正式规则或合规通过结论。
- 相同公司和国家不重复建立档案或义务。
- 不向其他国家档案泄漏中国默认值或候选义务。

## 后续里程碑

下一阶段建设中国企业画像、会计数据充分性、事实提供器和首批只读数据质量规则。税种适用性、阈值、税率和期限规则必须完成官方来源治理与中国财税专业签核后才能进入发布流程。
