# M43 中国风险规则依据可见性

## 目标

风险中心不能只展示“命中了什么风险”，还必须让用户看到该风险结论背后的规则版本、官方来源治理和专业签核状态。本次增量把规则依据摘要放到风险中心，让风险等级、下一步动作和官方依据状态在同一个页面可读。

## 已交付

- 在 `sudo.compliance.finding` 中国风险显示层新增：
  - `cn_risk_rule_basis_state`：缺少依据、来源需复核、专业待签核、规则需关注、依据可追溯。
  - `cn_risk_rule_source_count`：规则版本关联的官方来源数量。
  - `cn_risk_rule_release_state`：规则版本发布治理状态。
  - `cn_risk_rule_professional_state`：专业签核状态。
  - `action_cn_open_risk_rule_version()`：从风险事项打开对应规则版本。
- 中国风险中心列表新增依据状态、官方来源数量、发布状态和专业签核状态。
- 中国风险中心卡片新增“规则依据”区域和规则版本入口。
- 国家包能力增加 `china_risk_rule_basis_visibility`。
- 版本升级到 `19.0.1.40.0`，并新增迁移脚本刷新国家包元数据。

## 设计边界

- 本次只增强风险查看体验，不改变规则治理、规则发布、专业签核和评估引擎逻辑。
- “依据可追溯”表示规则版本具备受控来源、治理状态和专业签核状态，不代表系统替代专业判断。
- 当前运行库仍因服务器 PostgreSQL 故障无法做真实 Odoo 升级验证；已完成静态 XML/Python/插件契约校验。
