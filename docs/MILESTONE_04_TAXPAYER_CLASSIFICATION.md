# 里程碑 04：中国纳税人身份受控快照

## 目标

为税种适用性、申报频率和地方规则提供按评估日期可追溯的企业身份基础，避免系统根据公司名称、销售额、税码或会计科目猜测纳税人身份。

## 已实现

- 新增 `sudo.cn.taxpayer.classification`，按公司、合规档案和有效期保存身份快照。
- 记录省级主管辖区、地方税务辖区及受控编码、主管税务机关、增值税身份及申报频率、企业所得税身份及征收方式、个人所得税扣缴身份和适用会计制度。
- 核验前强制要求来源类型、来源日期、来源引用、范围与限制说明和证明附件。
- 只有合规管理员可以核验；不能通过普通 `create` 或 `write` 伪造核验状态。
- 修改受控字段后自动撤销核验，已核验记录不可删除。
- 核验校验和同时覆盖分类字段和附件内容；附件变化会在评估时形成 `checksum_mismatch`。
- 新增多公司记录规则和分层 ACL。
- 新增 `cn.taxpayer.classification_verified` 与 `cn.taxpayer.classification_detail` 两项事实。
- 新增 `CN-PROFILE-TAX-001` 内部资料准备度草稿规则及正反案例。

## 结论边界

- 系统只记录受控身份结论，不从 Odoo 销售额或科目余额推断一般纳税人、小规模纳税人、居民企业或征收方式。
- “已核验”表示来源、分类、有效期、附件和核验人已经固化，不表示税务机关认可或税法适用性已经自动成立。
- 没有评估日有效快照时输出数据缺失；存在未核验或完整性异常的快照时输出资料准备失败。
- 本里程碑不发布税率、门槛、期限或地方政策规则。
