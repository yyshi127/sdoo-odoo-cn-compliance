# 里程碑 03：中国基础控制规则草稿

## 目标

验证中国事实定义能够进入统一规则 DSL、规则测试和治理生命周期，同时确保未经官方来源治理和中国专业签核的规则绝不进入正式评估。

## 草稿规则

- `CN-BASE-REG-001`：中国企业登记资料准备度。
- `CN-ACC-PERIOD-001`：评估期间未过账凭证准备度。
- `CN-VAT-INV-READY-001`：业务发票税码映射准备度。
- `CN-ACC-EVIDENCE-001`：业务发票附件线索准备度。

## 治理边界

- 四条规则随包安装为 `draft`，专业签核状态为 `pending`。
- 当前不关联官方来源，因此发布门禁必然拒绝批准或生效。
- 每条规则具有正例和反例，但案例明确标记为内部控制测试，不冒充官方案例。
- 规则只描述 Odoo 数据准备度，不认定企业登记、会计处理、税率、抵扣或凭证保管是否合法。
- 正式发布仍需官方原文快照、来源哈希、适用范围、专业案例、独立审批和中国财税专业签核。
