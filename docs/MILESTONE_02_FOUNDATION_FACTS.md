# 里程碑 02：中国基础事实与数据缺口

## 目标

建立中国包首批只读事实提供器，验证 Odoo 会计和档案数据可以进入统一规则引擎，同时严格区分“观察到零”“没有资料”“资料不完整”和“配置冲突”。

## 已实现事实

- 统一社会信用代码受控登记值。
- 企业登记证明附件线索数。
- 财年结束日核实状态。
- 期间已过账和未过账凭证数。
- 期间已过账业务发票数。
- 已过账业务发票附件缺口数。
- 已过账业务发票业务行税码缺口数。
- 交易伙伴税务登记号缺口候选数。

## 结论边界

- 公司主数据中存在登记号码但没有受控登记记录时，质量标记为 `truncated`。
- 缺少登记或附件线索时标记为 `missing`，不能解释为通过。
- 多个同时有效的统一社会信用代码记录属于配置错误。
- 附件存在只表示线索存在，不表示内容真实、有效或已专业核验。
- 税码和伙伴主数据缺口只是准备度信号，不直接构成税务违法结论。
- 本里程碑不发布任何正式中国规则。
