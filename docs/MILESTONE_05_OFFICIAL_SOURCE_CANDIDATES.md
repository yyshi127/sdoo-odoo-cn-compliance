# 里程碑 05：官方来源候选清单

## 目的

为中国规则开发建立可追溯的官方来源入口，同时避免把“找到一个官方网址”误表示为“已治理、已生效的规则依据”。

本里程碑只登记来源候选项，不发布税率、申报期限、抵扣资格或其他法律结论。

## 受控状态

七项候选来源均满足以下状态：

- 国家/地区固定为中国。
- URL 使用财政部、国家税务总局或全国人大常委会官方 HTTPS 域名。
- 记录状态为 `draft`。
- 快照类型为不可发布的 `other`。
- 不预置快照附件、SHA-256、复核人或复核时间。
- 下次人工复核日为 `2026-10-15`。
- 所有关联规则版本仍为 `DRAFT-*`，专业复核状态仍为 `pending`。

## 从候选到可发布来源

必须依次完成以下步骤，任何一步都不得跳过：

1. 规则维护人员在 Odoo 中抓取官方网页或上传官方发布文件。
2. 系统保留原始二进制内容、采集 URL、时间、HTTP 元数据和大小。
3. 系统计算原文 SHA-256，并把快照标记为官方文件或官方网页留存。
4. 维护人员提交来源复核。
5. 与维护人员不同的审批人员核对标题、发布机构、版本、有效状态、原文完整性和适用范围。
6. 来源获批后，规则作者完成条款到事实、条件、结果、证据和整改动作的映射。
7. 正反例和边界案例全部通过，并完成影响分析。
8. 中国财税专业人员签核规则解释和适用范围。
9. 规则版本通过发布门禁后才能激活并进入正式评估。

## 自动门禁

`tools/validate_addon.py` 现在校验：

- 候选来源数量、XML ID 和 URL 唯一性。
- 仅允许受控官方域名和 HTTPS。
- 不允许候选记录预置有效状态、官方快照、哈希或复核信息。
- 下次复核日不得过期。
- 每条中国规则草稿必须引用已登记的来源候选项。
- 候选来源不能让草稿规则通过发布门禁。
- 当前版本必须包含升级迁移，并以追加方式保留用户已有来源关联。
