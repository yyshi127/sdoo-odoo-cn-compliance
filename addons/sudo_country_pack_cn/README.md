# Sdoo China Country Pack

`sudo_country_pack_cn` 是面向 Odoo 19 的中国财税合规国家包。

## 当前能力

- 注册中国国家包及其能力清单。
- 为中国公司建立草稿合规档案。
- 为档案补充七类候选义务。
- 为初始化向导提供统一社会信用代码登记默认值。
- 保证候选义务按公司隔离并可重复安全初始化。
- 提供十一项中国企业档案、纳税人身份和 Odoo 会计只读基础事实。
- 提供按有效期管理的中国纳税人身份快照及两项身份事实。
- 对身份来源、附件、管理人员核验和 SHA-256 完整性进行受控记录。
- 通过原生 Odoo 表单维护身份快照，并按允许公司隔离记录。
- 提供九条不会自动生效的内部控制规则草稿及二十一个正反和三态案例。
- 明确区分法定义务、税额计算、申报时限、内部控制和数据准备度。
- 汇总官方来源、规则测试、专业签核和技术审批形成发布就绪状态。
- 为九条规则草稿提供九份专业复核候选包和二十条官方来源定位。
- 将适用范围、前提、排除、结论边界、专业问题和引用定位绑定到规则与专业签核哈希。
- 专业签核前强制校验来源有效性、规则测试和复核包完整性，并提供单份原生 PDF 报告。
- 风险结果显示规则性质和结论边界，防止把准备度问题误写成违法结论。
- 登记九项官方网址候选来源，并以增量升级迁移安全补充规则关联。
- 对候选地址执行服务器端 TLS/HTTP 采集审计，不绕过证书和错误响应。
- 地址迁移仅修正从未采集的原始草稿，不覆盖用户已治理的来源快照。
- 提供六类受控外部数据集登记、原始附件封存和替代版本链。
- 区分内部封存、真实性验证、文件完整性和独立复核状态。
- 普通合规用户只读，合规管理员维护草稿并执行受控封存。
- 提供不可手工伪造的解析运行和规范化电子发票只读台账。
- 保留电子发票到多张会计凭证、多条借贷分录的原始关联结构。
- 失败解析不替代上一份成功结果，成功重跑形成可审计版本链。
- 区分零值、缺失、截断和配置错误，不把数据缺口解释为通过。
- 提供电子发票与 Odoo 供应商账单、会计凭证的只读账票勾稽工作台。
- 支持一张电子发票关联多个源会计凭证，不强制错误的一对一关系。
- 通过编号、往来方、币种、金额、税额、日期和凭证状态生成可解释候选。
- 真实性失败、主体不一致、重复源发票和关键字段缺失会阻断候选生成。
- 所有人工确认、拒绝、撤销和人工指定均保留人员、时间、说明及审计事件。
- 通过源发票、完整账簿范围、候选结果和单张凭证快照哈希检测后续变化。
- 提供增值税申报与税款缴纳的严格受控 JSON 契约和只读标准化台账。
- 严格区分零值与缺失，拒绝未知字段、重复 JSON 字段和声明数量不一致。
- 保留申报行、缴款构成、质量问题、版本链和多层 SHA-256 审计指纹。
- 未脱敏付款账号不会进入台账，普通合规用户仅能按允许公司只读查看。
- 提供 Odoo 账务、电子发票、增值税申报和税款缴纳的期间四方勾稽。
- 对五项金额口径分别给出是否可比较、差额、问题说明和建议下一步。
- 来源缺失、不完整、重复、主体不明或币种不一致时阻断比较，不以零值代替。
- 失败重跑不替代成功结果，新成功结果保留上一版本及完整审计事件。
- 普通合规用户可查看聚合结论，但底层会计凭证明细仍要求会计只读权限。
- 提供十项账票与增值税四方勾稽事实，将批次状态、复核计数、问题代码、逐项差异和审计指纹接入通用规则引擎。
- 事实适配严格要求同一档案、完全相同期间和唯一当前成功批次，不汇总模糊或重叠批次。
- 当前批次正在重算、审计字段缺失、计数不一致或存在重复当前结果时，规则事实会降级为过期、缺失或提取错误。
- 当前成功批次可发起精确期间规则扫描，勾稽类整改任务的验证复扫自动沿用原风险期间。
- 运行时测试覆盖规则扫描、风险、整改、证据和验证复扫关闭，但测试规则不会进入安装数据。
- 提供受控税务影响复核事项，将同一经济影响涉及的多条规则结果和勾稽问题归并，防止来源重复计量。
- 量化结论必须记录方向、计算过程、假设限制、工作底稿和系统内证据，并经过独立复核或受控同人例外。
- 潜在少缴、潜在多缴和期间错配影响分别汇总，不计算净额；待复核、无法量化和完整性异常事项不进入金额合计。
- 提供单批次增值税调节与税务影响 QWeb 报告，展示四方来源、账务申报调节链、逐项原始差异、受控影响事项和审计 SHA-256。
- 税务影响事项支持普通合规用户按公司只读查看，只有合规管理员可编制、提交、复核、退回和取消。
- 提供正式合规管理报告的编制、独立批准、签发、替代和撤回生命周期。
- 冻结规则、事实、风险、整改、证据、税务影响和 AI 元数据，并分别校验内容、批准与封存 PDF 的 SHA-256。
- 已签发报告不可改删或重新渲染；批准或 PDF 完整性异常时禁止下载正式文件。
- 发票台账索引采用流式审计摘要和 ORM 窄字段预取，在保持历史 SHA-256 兼容的同时限制大账套内存占用。
- 将当前成功的增值税四方勾稽结果桥接到通用申报与回执档案，不另建重复的申报生命周期。
- 正式申报要求公司级 `CN-VAT` 义务已确认适用、官方截止日依据有效、唯一受控申报记录可用并具有已验证回执证据。
- 标记已付款前要求申报应纳与有效缴款净额一致，并分别展示缴款成功、冲正和退库金额，不静默混同不同交易含义。
- 申报和缴款分别封存勾稽、标准化记录、官方依据与正式证据 SHA-256；来源被替代时保留历史快照并醒目标记非当前状态。
- 受控导入企业所得税季度预缴和年度汇算申报，分列账税利润、调整、税额、预缴及应补应退，并严格区分零值和字段缺失。
- 以一份按有效期和证据核验的会计利润口径覆盖全部有效损益科目，按明确借贷方向计算精确期间已过账会计利润。
- 分别勾稽账簿与来源申报会计利润、申报内部账税利润算术、应补与有效缴款本金、应退与已退库本金。
- 应补和应退保持独立方向，利息及滞纳金不混入本金；缺少来源、字段或控制时输出数据不足而不是通过。
- 企业所得税勾稽运行、逐项问题和五类 SHA-256 形成不可改写快照，并通过五项精确期间事实接入规则扫描和验证复扫。
- 提供企业所得税勾稽数据准备度草稿；即使金额存在差异，只要来源可比较仍可进入专业复核，不把“准备完成”误写成“金额一致”。
- 提供企业所得税差异复核内控草稿和受控三态处理器：来源阻断返回待确认，金额差异返回待复核，金额一致但有提示仍返回待确认，只有无差异无提示才通过。
- 两条企业所得税候选规则继续保持草稿、专业待签核和官方来源未治理状态，不会被正式评估自动选中。

## 重要边界

当前候选义务全部保持 `待确认`，不包含税率、申报期限或企业适用性结论。正式启用前必须补齐官方来源、公司级判断和专业签核。数据不足不能解释为合规通过。

官方网址候选项不是有效规则依据。候选项必须完成官方原文留存、SHA-256、独立复核和中国财税专业签核后，相关规则才可能进入发布流程。

专业复核候选包只用于组织真人审阅。包内条款定位、适用范围和问题清单不是法律意见，也不表示来源、规则或企业适用性已经获批；只有来源独立审批、规则测试、真人专业签核和技术审批全部完成后，规则才可能发布。

纳税人身份快照中的分类必须来自依法取得的受控材料并由合规管理员核验；系统不会根据公司名称、销售额或会计科目自动猜测纳税人身份。身份快照“已核验”只证明资料治理流程完成，不代表税务机关或专业人员已经认可全部税法结论。

外部数据集“已封存”只证明来源、范围、附件和复核轨迹已受控记录。真实性未验证、验证失败、抽样、部分覆盖或单人复核例外都会保持显式状态；系统不会因此宣称发票、申报或缴税数据已经获得税务机关认可。

规范化电子发票“字段校验正常”只表示规范化字段及金额关系通过内部检查，不等于源文件真实性通过，也不等于发票可抵扣、可税前扣除或已经正确申报。基础国家包不强制安装解析依赖；财政部 XBRL 解析能力由可选插件 `sudo_country_pack_cn_einvoice_xbrl` 受控启用。

账票勾稽只形成候选关系和人工复核记录，不修改 Odoo 会计凭证，也不自动作出抵扣、税前扣除、申报或违法结论。高可信候选仍必须由授权人员核对原件和已过账凭证后确认；账簿快照变化后必须重新勾稽。

申报与缴税标准化入口当前只接受 `sdoo.cn.tax-data.v1` 受控 JSON，不代表已经支持税务机关接口或任一税务软件的官方导出格式。导入结果不等于申报已提交、税款已扣缴或数据已经获得税务机关认可。

中国增值税受控申报缴款档案复用通用申报生命周期，但不会自动推断法定截止日、主管机关或企业适用性。截止日必须绑定已复核官方来源并记录人工计算说明；申报回执和缴款证明必须进入正式证据流程并完成验证。普通附件、标准化记录、四方金额一致或系统状态本身都不能替代税务机关回执，也不构成申报成功、足额缴税或税务合规结论。

企业所得税标准化台账只保存依法取得的来源申报值和审计指纹，不计算法定税率、优惠、扣除、亏损弥补、应纳税额或截止日。会计利润、纳税调增、纳税调减、应纳税所得额、预缴、应补和应退字段完整或相互勾稽，只能作为后续复核起点，不构成税务机关认定或企业所得税合规结论。

企业所得税账税与缴退税勾稽只验证当前受控口径和来源字段是否可比较、算术是否一致。系统不会根据科目名称推断税法调整，也不判断税前扣除、税率、优惠、亏损弥补、关联交易或跨境处理是否合法。勾稽差异只形成待人工复核事项，不自动等同于少缴、多缴、违法或可确认税务影响；勾稽一致也不等于申报合法、足额缴税或企业所得税合规。

企业所得税数据准备度与差异复核规则均是候选内部控制，不是已经发布的税法规则。数据准备度通过只表示当前来源可以比较；内控失败只表示存在一个或多个算术差异项目；待确认表示数据不可比较、状态矛盾或仍有提示。任何状态都不能脱离受控原文、企业适用性判断和中国财税专业人员签核而用于对外合规结论。

增值税期间四方勾稽支持两层独立账务口径：发票税额用于账票比较，经过证据核验和有效期控制的增值税控制科目发生额用于账务到申报比较。经过审批的申报调整可以按精确期间叠加形成受控申报比较口径。缺少完整销项或进项映射、部分期间覆盖、重复配置、证据哈希失效或调整未批准都会阻断比较。新增调节与税务影响报告用于组织受控勾稽及专业复核工作底稿，仍不是法定申报表；未开票收入、视同销售、进项转出、留抵等事项必须通过正式规则、完整数据和人工复核确认。勾稽一致只代表当前受控口径金额一致，不等于税务合规结论；勾稽差异也不自动等同于税务风险或违法。

勾稽事实不会把五类差异简单相加为“税务影响额”，因为同一税额可能在账票、账申报和申报缴税比较中重复出现。税务影响复核事项按同一经济事项归并来源，并把尚未评估、无法量化、初步金额和已复核金额明确分层；只有证据、计算和复核 SHA-256 均完整的已复核事项进入少缴、多缴或期间错配分项汇总，证据变化后金额会立即退出汇总。产品包当前仍没有生效的中国规则；“发起规则扫描”只有在规则完成官方来源治理、独立审批、中国财税专业签核并生效后才会形成正式评估。复核金额也不等于申报金额、税务机关认定或法律意见。
